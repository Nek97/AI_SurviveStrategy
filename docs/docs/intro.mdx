# Introduction to AI Survive Strategy

Welcome to the official documentation of **AI Survive Strategy**. 

This project is a strategic simulation where AI-driven agents must survive, adapt, and cooperate (or compete) in a dynamic environment.

## Getting Started

Explore the sidebar to discover:
- The results of the behavioral and ethical simulations.
- The mechanics of the game engine.

You can find the complete source code and instructions for local installation in our [GitHub repository](https://github.com/Nek97/AI_SurviveStrategy).
