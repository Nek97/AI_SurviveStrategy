# Introduzione ad AI Survive Strategy

Benvenuto nella documentazione ufficiale di **AI Survive Strategy**. 

Questo progetto è una simulazione strategica in cui agenti guidati dall'intelligenza artificiale devono sopravvivere, adattarsi e cooperare (o competere) in un ambiente dinamico.

## Come Iniziare

Esplora la barra laterale per scoprire:
- I risultati delle simulazioni comportamentali ed etiche.
- Le meccaniche del motore di gioco.

Puoi trovare il codice sorgente completo e le istruzioni per l'installazione locale nella nostra [repository GitHub](https://github.com/Nek97/AI_SurviveStrategy).
